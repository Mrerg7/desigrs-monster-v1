# desigrs.monster

Premium domain sales landing page for **desigrs.monster**.

## Stack

- Astro 7 (pure static output)
- Tailwind CSS v4 via `@tailwindcss/vite`
- Content Collections
- Cloudflare Workers Static Assets (no adapter)
- Structured data + full OG meta
- Sitemap + robots.txt

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
npx wrangler deploy
```

Or:

```bash
npm run deploy
```
